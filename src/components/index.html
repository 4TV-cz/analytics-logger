Applies straight away so you can see it; Cancel puts it back. Stored per browser, not in the proxy config.
Port the device sends requests to. Ports below 1024 require Administrator on Windows. The proxy restarts on save.
Separator between the proxy address and the upstream URL in the request path (e.g. /;https://<env>.litix.io, /;https://www.google-analytics.com). Only the path portion is matched, so the proxy's host:port doesn't matter. Leave empty to treat the whole request URL as the upstream.
For SDKs that only take a base URL (e.g. the mParticle Roku SDK): one /prefix https://upstream-host per line. A request to http://<proxy>:8889/mparticle/v2/… is forwarded to https://nativesdks.mparticle.com/v2/….
When enabled, absolute http/https URLs found in JSON response bodies are prefixed with this proxy's address + Client URL prefix so the client routes them back through the proxy. Off by default — analytics responses go back untouched. Requires Client URL prefix to be set.
HLS playlists mostly reference their variants and segments relatively ("../../chunklist-d.m3u8"), which a player cannot resolve once it fetched the playlist from the proxy. When enabled, every reference in an m3u8 — bare lines and URI="…" tag attributes alike — is resolved against the playlist's own URL and routed back through the proxy. Requires Client URL prefix to be set.
Once exceeded, the oldest entries are deleted from disk. 0 disables the cap.
Same, by total size of the logs folder. Whichever limit is reached first starts evicting. 0 disables the cap.
When a request aimed at the proxy itself contains this substring, the proxy responds 200 OK without forwarding and clears the capture — the same as the Clear button: every log file is deleted from disk and the view is emptied. The delete finishes before the 200 comes back, so requests sent after it are safe. Leave empty to disable.
Call this URL from the device (or any browser, or your deploy script) to start a session from scratch. Read-only; derived from the proxy's LAN address, port and the pattern above.
